基于 Steam 版本；已验证 AppID 1025600、Build ID 25733254，以及清单中37项原版资源 SHA256。其他 Build ID 或未知修改不兼容，不会放宽校验覆盖。

安装与还原
1. 本包为非官方测试版，可能存在兼容问题。安装前自行备份存档和原文件；安装器的37项资源备份不包含存档。
2. 在 Steam 库中右键 Battle Realms → 管理 → 浏览本地文件，找到自己的游戏根目录。通常相对位置为 steamapps\common\Battle Realms，不要选 Data 或 Interface 子目录。
3. 把 ZIP 完整解压到游戏目录外的普通文件夹，保留 EXE、清单、差分和所有附带文件。正常退出游戏，双击“BR汉化安装器.exe”，先粘贴或确认游戏根目录，再输入 1 安装。路径可含空格、可带双引号。
4. 本修订支持认证旧 r1 和当前版资源。检测到旧版时，必须先找到37项齐全且与已验证原版哈希一致的备份，才会从原版副本构建本版后升级。未知 MOD、损坏资源或没有可信备份时会停止；不会直接覆盖放行。
5. 还原时运行同一完整安装器，填写同一游戏根目录，再输入 2。程序逐个核对备份，不会只取最新目录；不完整或损坏的备份会跳过。原版资源、旧备份和旧日志保留，新操作另建备份及恢复记录。当前已经是37项原版时不重复替换。
6. 安装成功显示“安装完成，按 Esc 退出”；还原成功显示“还原完成，按 Esc 退出”。只有对应37项哈希全部校验通过才显示成功。失败会显示原因并停留，按键盘 Esc 键关闭，单独回车不会关闭。日志在安装器旁 logs 文件夹，不可写时在 %TEMP%\BRZH-logs。
7. 操作中断后保留游戏根目录 BRZH-backups 内所有文件，关闭游戏后可重试本安装器的 2 还原。存在暂存冲突、未知修改或备份全部不可用时停止，不要自行删除备份或反复覆盖。

异常恢复
发现异常请停止使用补丁。Steam 库中右键游戏 → 属性 → 已安装文件 → 验证游戏文件的完整性，按 Steam 提示修复官方文件。
Steam 验证通常会重新下载被修改或损坏的官方文件；不保证删除补丁额外新增文件。此安装器也不承诺百分之百一键彻底清除全部额外文件。保留备份和错误日志，必要时联系维护者。
