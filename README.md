# Battle Realms 简体中文补丁

适用于 **Battle Realms: Zen Edition 的 Steam 版，build 25733254**。本项目借助 GPT-6 制作，并进行人工文本校对。

**[下载 v0.95 r2（测试版）](https://github.com/Katafractoi/Battle-Realms-ZH/releases/download/v0.95/BRZH-v0.95-Steam-build25733254-r2.zip)** · [版本说明](https://github.com/Katafractoi/Battle-Realms-ZH/releases/tag/v0.95)

## 安装与还原

1. 退出游戏，先备份存档。在 Steam 库右键游戏 → 管理 → 浏览本地文件，找到游戏根目录。
2. 将下载的 ZIP 完整解压到游戏目录外的普通文件夹，运行 `BR汉化安装器.exe`，填写游戏根目录。
3. 输入 `1` 安装，或输入 `2` 还原。完成或报错后，按键盘 **Esc** 退出。

还原需要完整、可校验的原版备份；请保留安装器生成的备份。其他游戏版本或未知修改可能被拒绝，详细恢复步骤见包内 README。
